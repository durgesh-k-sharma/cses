# CSES Solutions

VitePress site for [CSES Problem Set](https://cses.fi/problemset/) solutions and writeups.

**Live:** https://durgesh-k-sharma.github.io/cses/

## Develop

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
npm run docs:preview
```

Deployed from `main` via GitHub Actions to GitHub Pages at `/cses`.
