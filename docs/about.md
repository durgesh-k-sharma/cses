# About

This site tracks my solutions to the [CSES Problem Set](https://cses.fi/problemset/) — a curated collection of competitive programming problems spanning algorithms and data structures.

## Goals

- Keep a durable, searchable record of approaches after solving
- Document complexity and edge cases that are easy to forget

## Status

Pages appear as problems are solved. Empty section indexes mean that category is still in progress.
