# Conventions

How writeups are structured on this site.

## Page template

Each solved problem page generally includes:

1. **Problem** — short restatement and link to CSES
2. **Approach** — intuition and algorithm choice
3. **Complexity** — time and memory
4. **Solution** — reference implementation
5. **Notes** — pitfalls, alternatives, or related problems (optional)

## Frontmatter

```md
---
title: Weird Algorithm
problem: https://cses.fi/problemset/task/1068
tags: [simulation, math]
difficulty: easy
---
```

## Code

- Prefer clear, contest-style C++ unless noted otherwise
- Assume competitive-programming I/O habits (`ios`, fast input) when relevant
- Highlight the core idea in comments sparingly

## Sections

Sidebar sections match the official CSES categories. Unsolved sections stay as stubs until the first writeup lands.
